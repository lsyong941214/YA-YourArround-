# CHANGELOG

## v0.4.0 - 이장님 연락처 플로우 1단계 구현
- 하단 탭바 아이콘 반영(홈/매칭/마을/알림/마이페이지), "알림" 탭을 "메시지"로 변경(아이콘도 Send로 교체)
- 홈 대시보드의 "이장님 연락처" 카드를 클릭하면 `/chief`(이장님 목록)로 이동하도록 연결
- 이장님 목록 페이지 신규 구현 (`/chief`, `src/components/chief/ChiefListScreen.tsx`)
  - 등록된 이장님들을 리스트업, 선택 시 해당 이장님 상세 페이지로 이동
- 이장님 상세(주민 목록) 페이지 신규 구현 (`/chief/[jang_id]`, `src/components/chief/ChiefDetail.tsx`)
  - 시안 이미지(1단계: 이장님 연락처) 그대로 재현: 프로필, 신뢰도, 연결 성사/활동 주민 통계, 주민 목록/연결 내역 탭, 주민별 하트 버튼
  - 주민 카드의 하트를 누르면 해당 주민과의 연결 요청 화면(`/chief/[jang_id]/request/[memb_id]`, 현재는 placeholder)으로 이동
  - 하단 버튼 문구를 "이장님에게 직접 요청하기"로 변경
  - 탭 전환, 알림 아이콘, 하단 버튼 등 나머지 상호작용은 빈 함수로 자리만 잡아두고 추후 구현 예정
- 이장님/주민 목업 데이터 모듈 추가 (`src/lib/data/jang_data.ts`)

## v0.3.0 - 홈 대시보드(3번째 화면) 구현 및 로고 하트 제거
- "주변" 로고 옆 하트 아이콘을 전체 페이지(로딩/로그인)에서 제거
- 홈 대시보드(3번째 화면) 신규 구현 (`src/components/home/HomeScreen.tsx`)
  - 상단 헤더(로고, 알림, 포인트), 프로필 카드(인사말 + 소개 문구)
  - 프로필 사진의 작은 연필 아이콘을 누르면 사진 업로드 + 소개 문구 수정 모달(`ProfEditModal.tsx`)이 열림
    - 실제 서버 업로드 연동 전까지는 로컬 미리보기(`URL.createObjectURL`)로 동작
  - "내 역할" 카드를 탭하면 주민 ↔ 이장님으로 전환되며, 매칭 관련 문구도 함께 변경
    - 주민: "남은 매칭 시도 3/5회" / 이장님: "진행중인 매칭 2/5"
  - "이장님 연락처" 카드는 역할과 무관하게 동일하게 노출 (연락처 이장님 수 / 추천 주민 수)
  - "주변 가이드 투어", "이장님 추천 주민" 리스트, 하단 탭바(홈/매칭/마을/알림/마이페이지)는 디자인만 반영, 클릭 동작은 추후 개발
- 주민 상세 프로필 페이지 신규 구현 (`/resident/[memb_id]`, `src/components/resident/MembDetail.tsx`)
  - 홈 화면의 추천 주민 카드를 클릭하면 이동
  - 프로필/소개 정보 표시, 하단 "이장님께 요청하기" / "직접 매칭시도" 버튼(추후 업데이트 예정 안내)
- 추천 주민 목업 데이터 모듈 추가 (`src/lib/data/memb_data.ts`), 홈/상세 페이지에서 공용으로 사용
