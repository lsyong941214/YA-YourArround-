# 개인정보 수집 항목 정리 (체크리스트 8·9번 대응)

작성일: 2026-09-20. 서비스 출시 체크리스트 8번("민감정보는 최소한으로 수집") 대응으로,
현재 코드가 실제로 수집·저장하는 개인정보 항목을 정리한다. 이 문서는 법무 검토를 거친
정식 개인정보처리방침이 아니라, 방침 작성 시 그대로 옮겨 쓸 수 있는 **개발팀 기준 원장**이다.
정식 방침 문서화·게시(체크리스트 9번의 남은 TODO)는 별도로 법무 검토가 필요하다.

## 1. 수집하는 항목

| 항목 | 저장 위치 | 필수 여부 | 비고 |
|---|---|---|---|
| 로그인 ID | `auth.users.email` (내부 로그인용 가짜 이메일) | 필수 | 카카오/네이버/구글 실연동 전까지는 비밀번호 로그인만 사용 |
| 비밀번호 | Supabase Auth (해시 저장, 앱 코드에서 평문 접근 불가) | 필수 | Supabase Auth가 관리, 별도 컬럼 없음 |
| 이름(닉네임) | `profiles.user_name` | 필수 | 실명 여부는 사용자 입력에 달림, 실명 강제 없음 |
| 역할(주민/이장) | `profiles.user_role` | 필수 | 서비스 이용 형태 구분용 |
| 생년월일 | `profiles.birth_dt` | 필수 | 연령 검증(만 19세 미만 가입 차단)에만 사용, 화면엔 나이만 노출 |
| MBTI | `profiles.user_mbti` | 필수 | 매칭 참고용 |
| 직업 | `profiles.user_job` | 선택 | 자유 텍스트 |
| 지역 | `profiles.user_reg` | 선택 | **2026-09-20부터 12자 제한** — 시/구 단위까지만, 상세 주소 입력 차단 (`REG_MAX`, DB CHECK 제약) |
| 소개 문구 | `profiles.user_bio` | 선택 | 60자 제한, 불법 광고 키워드 필터 적용 |
| 프로필 사진 / 앨범 사진 | Supabase Storage + `profiles.avatar_url`/`photo_urls` | 필수(프로필 사진) / 선택(앨범) | 앨범 최대 6장 |
| 채팅 메시지 | `public.chat_messages` | - | 대화 당사자만 RLS로 조회 가능 |
| 신고/차단 기록 | `public.reports`, `public.user_blocks` | - | 신고자·대상·사유만 저장, 신고 사유는 정해진 enum 값 |

## 2. 수집하지 않는 항목 (명시적 확인)

- **정밀 위치정보(GPS 좌표)** — 수집 기능 자체가 코드에 없음. `user_reg`는 자유 텍스트일 뿐
  기기 위치와 연동되지 않는다.
- **성적 지향, 종교, 정치 성향 등 민감정보** — 프로필 입력 항목에 없음.
- **주민등록번호 등 법정 식별번호** — 수집하지 않음. 연령 확인은 생년월일 자율 입력만으로
  처리한다(공적 신분증 검증은 하지 않음 - 후속 과제로 남겨둠).
- **정확한 상세 주소** — `user_reg`는 2026-09-20부터 12자 제한 + 입력 가이드 문구로
  시/구 단위까지만 받도록 제한했다(`OnbdScreen.tsx`, `ProfEditModal.tsx`,
  `supabase/schema.sql`의 `profiles_user_reg_check` 제약, 기존 프로젝트는
  `supabase/alter_min_pii.sql`).

## 3. 보관 기간 (현재 상태 - 정책 미정)

- 탈퇴(계정 삭제) 기능 자체가 아직 앱에 없어, 실질적인 보관기간 정책이 정의되어 있지 않다.

  연쇄 삭제되도록 FK는 구성되어 있으나, 탈퇴 트리거(UI/API)가 없어 실제로는 삭제되지 않는다.
